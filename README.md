## Собственный проект

тема проекта: магазин

главный класс: Product

почему этот объект нужен программе:
класс нужен чтобы не создавать кучу отдельных переменных для каждого товара а хранить все данные об одном товаре в одном месте

какие данные хранит объект:

- Name - название товара
- Price - цена
- Category - категория
- Stock - количество на складе
- IsAvailable - есть ли товар в наличии

какие значения задаются через конструктор:
название цена категория и остаток на складе потому что эти данные у каждого товара свои

какие значения можно задавать автоматически:
поле IsAvailable задается автоматически как true потому что когда добавляешь новый товар в магазин он обычно сразу есть в наличии
